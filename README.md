## 02. Reinforcement Learning for Adaptive Traffic Control
### Q-Learning-based Adaptive Traffic Signal Control

- Built a digital twin of the Gangnam Station intersection using real traffic data
- Developed an adaptive traffic signal controller based on Tabular Q-Learning
- Reduced the state space from approximately **1.56 million to 100 states** through state abstraction
- Achieved stable convergence under a large-scale traffic simulation environment

## 04. Active Damper System Using Shear-Thickening Fluid
### Ultrasound-controlled STF Active Damper

- Designed and manufactured a 1-DOF vibration test system and STF damper
- Conducted rheological characterization, repeated vibration tests, and non-Newtonian fluid analysis
- Investigated active damping control using 40 kHz ultrasonic excitation
- Reduced the low-RPM vibration peak by approximately **25%** and transmitted force by approximately **30%**

## 05. Fan-out WLCSP Package Warpage Analysis
### Effect of EMC Thickness and Material Properties on Package Warpage

- Analyzed thermal deformation of Fan-out WLCSP packages using ANSYS
- Compared warpage according to EMC thickness and material properties
- Evaluated structural behavior under thermal loading conditions
- Derived a minimum deformation of **100.76 μm** under the selected design condition
